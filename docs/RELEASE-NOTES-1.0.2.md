# Server Dashboard 1.0.2

Mobile Frontend Fix.

Дата выпуска: 2026-09-19

## Изменения

- исправлена мобильная шапка Dashboard;
- название `Server Name + Dashboard` теперь помещается в одну строку;
- уменьшены высота шапки и размеры элементов управления;
- исправлена видимость кнопки мобильного меню;
- верхние кнопки остаются в одной строке на узких экранах;
- положение бокового меню синхронизировано с новой высотой шапки;
- добавлена дополнительная адаптация для экранов до 390 px.

## Совместимость

Изменений backend, RPC protocol, схемы конфигурации, API модулей и модели безопасности нет.

Локальные extensions сервера в релиз не входят.

## Обновление

Это frontend-only patch-release поверх 1.0.1.
