# Server Dashboard 1.0.0

Первый стабильный публичный выпуск.

В него входят основные страницы мониторинга и управления, разделение непривилегированной веб-части и привилегированной службы, настраиваемые списки разрешённых действий, локальная документация, журнал действий и API модулей версии 1.

Серверно-зависимые функции вынесены во внешние модули и не входят в ядро. В качестве отдельного проекта подготовлен модуль Backup Monitor для контроля резервных копий.

Перед публикацией версия прошла статические проверки, автоматические тесты и отдельную проверку границ модульной архитектуры. История внутренних тестовых сборок в публичный журнал изменений не переносится.
