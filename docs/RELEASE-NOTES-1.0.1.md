# Server Dashboard 1.0.1

Frontend Fix.

Дата выпуска: 2026-09-17

## Изменения

- favicon для Dashboard и страницы входа;
- обновлённые и визуально различимые иконки верхней панели;
- отдельная иконка перезагрузки;
- индикатор текущей загрузки CPU на странице «Обзор»;
- live-обновление индикатора CPU;
- небольшие исправления и выравнивание интерфейса;
- поддержка `media-src 'self' blob:` в примере Nginx CSP для внешних модулей с HTML5 media;
- шаблон внешнего модуля теперь включает отдельный `module.css`;
- документация закрепляет разделение core CSS и стилей extensions;
- стили и собственные иконки внешних модулей должны использовать namespace модуля;
- удалён лишний `!important` из обычного CSS-правила Fail2Ban.

## Совместимость

Изменений RPC protocol, конфигурационной схемы и API модулей нет.

Локальные инфраструктурные extensions не входят в релиз.

## Обновление

Для существующей установки достаточно обновить core-файлы с сохранением локальной конфигурации, секретов и внешних модулей.
