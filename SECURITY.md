# Безопасность

## Поддерживаемые версии

Исправления безопасности выпускаются для последней опубликованной версии Server Dashboard.

## Как сообщить об уязвимости

Не публикуйте сведения о ещё не исправленной уязвимости в обычном GitHub Issue.

После публикации репозитория используйте приватную форму GitHub Security Advisories:

1. откройте вкладку **Security** репозитория;
2. выберите **Report a vulnerability**;
3. опишите затронутую версию, условия воспроизведения и ожидаемое влияние;
4. по возможности приложите небольшой пример конфигурации или журнал без секретов.

Если проблема не связана с безопасностью, используйте обычный GitHub Issue.

## Что полезно указать

- версию Server Dashboard;
- версию внешнего модуля, если проблема относится к нему;
- версию ОС, Python, PHP и Nginx;
- включённые модули;
- точные шаги воспроизведения;
- ожидаемое и фактическое поведение.

Не прикладывайте `secrets.ini`, пароли, токены, закрытые ключи и другие секреты.

Подробная модель безопасности проекта описана в [docs/SECURITY.md](docs/SECURITY.md).
