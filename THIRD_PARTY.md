# Сторонние компоненты

Server Dashboard не загружает JavaScript или CSS со сторонних CDN. Необходимые значки хранятся локально.

## Bootstrap Icons

Часть SVG-значков основана на проекте Bootstrap Icons, который распространяется по лицензии MIT. Текст лицензии сохранён в `docs/BOOTSTRAP-ICONS-LICENSE.txt`.

## markdown-it-py

Для преобразования Markdown в HTML используется системный пакет `markdown-it-py` 3.x. Он не включён в архив Server Dashboard и устанавливается отдельно. Проект `markdown-it-py` распространяется по лицензии MIT.
