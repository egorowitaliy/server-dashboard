# История изменений

## 1.0.2 — 2026-09-19

Mobile Frontend Fix.

- шапка Dashboard на мобильных экранах уменьшена по высоте;
- название сервера и продукта размещается в одну строку;
- исправлена кнопка открытия мобильного меню;
- кнопки верхней панели компактнее и не переносятся;
- скорректировано положение бокового меню с учётом новой высоты шапки;
- добавлена дополнительная адаптация для экранов до 390 px.

## 1.0.1 — 2026-09-17

Frontend Fix.

- добавлен favicon для интерфейса и страницы входа;
- переработаны иконки действий в верхней панели;
- для перезагрузки добавлена отдельная иконка;
- в блок состояния сервера добавлен индикатор загрузки CPU;
- индикатор CPU обновляется вместе с live-данными страницы;
- выровнены мелкие детали интерфейса;
- CSP примера Nginx дополнен поддержкой `blob:` media для внешних модулей.
- шаблон внешнего модуля дополнен собственным `module.css`;
- в документации закреплено разделение стилей core и extensions;
- специфичные CSS-классы и иконки extension должны иметь собственное пространство имён;
- удалён лишний `!important` из стилей Fail2Ban; системный `[hidden]` сохранён как инвариант.

## 1.0.0 — 2026-09-13

Первый публичный стабильный выпуск Server Dashboard.

- обзор состояния Linux-сервера;
- контроль служб systemd, Docker, Fail2Ban, дисков, SMART и расписания;
- ограниченные административные действия через отдельную привилегированную службу;
- авторизация, CSRF-защита, ограничение попыток входа и журнал действий;
- отключаемые страницы и компоненты;
- просмотр локальной документации Markdown;
- API модулей версии 1 для локальных расширений;
- единый набор компонентов интерфейса для встроенных и внешних модулей;
- компактный подвал интерфейса со ссылками на сайт автора и Telegram;
- раздельное хранение кода, конфигурации, секретов, журналов и локальных расширений;
- примеры конфигурации для Debian-подобной системы с Nginx и PHP-FPM;
- набор автоматических проверок для основных границ безопасности и совместимости модулей.
